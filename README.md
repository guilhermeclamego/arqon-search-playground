# arqon-search-playground

An interactive sandbox and integration test environment for the **ArqonSearch** library.

## Features

- **Hands-On Sandbox:** Run full-text search queries using the unified `arqon-search-core` DSL.
- **Local Multi-Engine Stack:** Pre-configured `docker-compose.yml` with MongoDB (ReplicaSet enabled for Atlas Search) and Elasticsearch.
- **Real-World Verification:** Test query translations, pagination, and multi-field matching against live databases.
